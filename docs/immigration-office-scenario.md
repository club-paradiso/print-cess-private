# 출입국관서 민원인 서류 출력 시나리오

이 문서는 출입국관서(출입국·외국인관서) 민원 창구에서 print-cess **방문자 인쇄 모드**
(`/visitor`)를 이용해 민원인의 서류를 출력하는 표준 시나리오를 설명합니다.
로그인·앱 설치·회원가입 없이, 휴대전화에서 보내고 카운터에서 바로 출력합니다.

## 등장인물과 화면

- **민원인**: 자신의 휴대전화로 서류를 업로드하는 방문자.
- **창구 직원**: 카운터 화면(`/visitor`)을 보고 QR을 제시하고 출력을 확인하는 직원.
- **카운터 화면** (`/visitor`): 방문자용 QR 코드, 진행 단계(QR 스캔 → 서류 업로드 →
  키오스크 출력 → 자동 파기), 세션 만료 타이머를 표시합니다.
- **휴대전화 화면** (`/s/:sessionId`): QR 속 링크로 열리는 업로드 화면. 서류를
  선택하면 종단간 암호화되어 서버에 업로드됩니다.

## 시나리오 단계

### 1. 방문자 도착 — QR 제시

1. 민원인이 서류 출력이 필요하다고 말하면, 직원은 카운터 화면의 **새 방문자 세션**
   버튼이 눌러져 있는지 확인합니다.
2. 카운터 화면에는 해당 민원인 전용 QR 코드와 함께 "세션 만료까지 10:00" 같은
   타이머가 표시됩니다. 이 시간이 지나면 세션은 무효화되고 업로드된 파일은
   자동으로 파기됩니다.

### 2. QR 스캔 — 휴대전화 연결

1. 민원인은 자신의 휴대전화 카메라로 QR 코드를 스캔합니다.
2. 휴대전화에 업로드 화면이 열리면 세션이 `claimed` 상태가 되고, 카운터 화면의
   진행 단계가 "QR 스캔"에서 "서류 업로드"로 넘어갑니다.
3. 세션이 만료되기 전에 스캔하지 못하면 카운터 화면에 만료 안내가 표시되고,
   직원이 새 세션을 만들어 다시 안내합니다.

### 3. 서류 업로드 — 암호화 전송

1. 민원인이 휴대전화에서 출력할 서류(PDF, 이미지 등)를 선택해 업로드합니다.
2. 파일은 휴대전화에서 암호화된 뒤 서버에 저장되며, 서버는 파일 내용을 해독할
   수 없습니다.
3. 업로드가 끝나면 카운터 화면의 단계가 "키오스크 출력"으로 넘어갑니다.

### 4. 직원 확인 — 출력

1. 직원은 카운터 화면에서 업로드 완료를 확인하고, 민원인에게 출력 매수와
   서류 내용을 확인받습니다.
2. 직원이 출력하면 파일이 카운터 프린터로 전송되어 인쇄됩니다.
3. 인쇄 중 오류가 발생하면 카운터 화면에 실패 안내가 표시되고, 파일은 서버에
   남지 않도록 정리됩니다.

### 5. 출력 완료 — 자동 파기

1. 출력이 완료되면 세션이 `completed` 상태가 되고, 서버의 암호문 파일은 즉시
   삭제됩니다.
2. 카운터 화면에는 "출력이 완료되었습니다. 서버의 파일은 자동으로 파기되었습니다"
   안내가 표시됩니다.
3. 민원인이 출력물을 수령하면 절차가 끝납니다. 다음 민원인을 위해 직원이
   새 방문자 세션을 만듭니다.

## 예외 처리

| 상황                       | 카운터 화면 표시        | 조치                                                |
| -------------------------- | ----------------------- | --------------------------------------------------- |
| 세션 만료(미스캔·미업로드) | "세션이 만료되었습니다" | 업로드된 파일이 자동 파기됨. 새 세션 생성 후 재안내 |
| 업로드 실패                | "인쇄에 실패했습니다"   | 네트워크 확인 후 새 세션으로 재시도                 |
| 인쇄 실패                  | "인쇄에 실패했습니다"   | 프린터 상태 확인 후 새 세션으로 재시도              |
| 민원인 취소 요청           | "인쇄가 취소되었습니다" | 업로드된 파일 파기됨. 절차 종료                     |

## 개인정보 보호 포인트

- 업로드된 서류는 출력 완료 또는 세션 만료 즉시 서버에서 삭제됩니다. 창구 직원이
  별도로 삭제할 필요가 없습니다.
- 방문자 대기열이 길어 세션 만료가 잦으면 `VISITOR_TTL_SECONDS`를 최대 1800초
  (30분)까지 늘릴 수 있습니다. 30분을 초과하는 값은 설정 검증에서 거부됩니다.
- 개발·Preview·픽스처·CI에는 실제 민원 서류를 절대 사용하지 않습니다.
- 기관의 내부 보안지침에서 외부 웹서비스 사용이 허용된 문서 분류에 한해
  사용합니다.
